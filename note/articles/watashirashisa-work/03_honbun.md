# 「このままでいいのかな」と思った夜に。1回15分×4夜、点数をつけずに『私らしさ』を言葉にするセルフワーク

## はじめに：「やりたいことは？」と聞かれて、言葉に詰まったことはありますか

「やりたいことは何？」
そう聞かれて、すぐに答えられなかったことはありますか。

答えられない自分に、少しがっかりしたかもしれません。
まわりの人は、みんなちゃんと分かっているように見えるから。

このnoteは、そんな夜のために書きました。
やりたいことが分からないままでも、大丈夫です。

【要一次情報：オーナー自身が「やりたいことは？」と聞かれて言葉に詰まった場面がほしい（いつごろ・誰に・どんな気持ちになったか。2〜4文程度）】

ここでは、点数をつけない、正解を探さない、ひとりでできるワークを紹介します。
1回15分を4つの夜に分けて、ゆっくり進めていきます。

## 「やりたいこと」が見つからないのは、あなたのせいじゃない

見つからないのは、あなたの努力が足りないからではありません。
探し始める「順番」と、まわりから聞こえる「声」が関係していることが多いのです。

### いきなり「やりたいこと」から探すと、迷子になりやすい理由

やりたいことは、最初ではなく、最後に見えてくるものだと私は考えています。

「やりたいこと」は大きな問いです。
いきなり答えを出そうとすると、手がかりがないまま考えることになります。
そして「何も出てこない私」を責めてしまいがちです。

このワークでは、順番を逆にします。

1. まず「心地いい」と「ちょっと嫌」を集める
2. そこから「大切にしたいこと」を見つける
3. 最後に「理想の未来」を描く

小さな感覚から始めると、大きな問いにも少しずつ近づけます。

【要一次情報：オーナーが「探す順番が逆だった」と気づいたきっかけがほしい（いつ・何があって・どう考えが変わったか）】

### 「〜しなきゃ」の声が、本当の声をかき消していることがある

「ちゃんとしなきゃ」「そろそろ決めなきゃ」。
そんな声が大きいと、自分の小さな気持ちは聞こえにくくなります。

その声は、家族や職場、SNS、世間の「ふつう」から来ていることもあります。
どれも悪いものではありません。
ただ、それは「あなたの声」とは別のものかもしれません。

このワークでは、「〜しなきゃ」を消そうとはしません。
ただ、そっと横に置いておきます。
そのうえで「私はどう感じる？」に耳を傾けてみます。

### 30歳前後で揺れるのは、ごく自然なこと

人生の節目で立ち止まるのは、自然なことです。

30歳前後の揺れは「クォーターライフクライシス」と呼ばれ、キャリア系のメディアでも取り上げられるようになりました。
揺れているのは、あなただけではありません。

揺れるのは、これまでの自分を見直す時期が来たというサインかもしれません。
責めなくていいんです。

## STEP1（1夜目）：「心地いい」と「ちょっと嫌」を集める

1夜目は、ただ集めるだけです。分析も評価もしません。

お試しワークで書いたメモがあれば、隣に置いておきましょう。

### 過去をふり返る問い

全部に答えなくて大丈夫です。書けそうなものから選んでください。

1. 子どものころ、時間を忘れて夢中になっていたことは何ですか。
2. 学生時代、誰に頼まれたわけでもないのに続けていたことは何ですか。
3. これまでで「あの時間はよかったな」と思い出す場面はどこですか。
4. 人から「ありがとう」と言われて、素直にうれしかったのはどんなときですか。
5. 「あれはもう二度とやりたくない」と思ったことは何ですか。

### 今をふり返る問い

6. この1か月で、ちょっとうれしかった場面はどこですか。
7. この1か月で、モヤっとした場面はどこですか。
8. 気づくと時間が過ぎている、と感じるのは何をしているときですか。
9. 誰といるとき、肩の力が抜けますか。
10. 最近、「本当はこうしたかったな」と思ったことはありますか。

### 「ちょっと嫌」も大事な手がかりになる理由

「嫌」は、大切にしたいものの裏返しであることが多いからです。

たとえば「急かされるのが嫌」なら、「自分のペースで進めたい」が隠れているかもしれません。
「嘘をつかれるのが嫌」なら、「誠実さ」を大切にしているのかもしれません。

だから、ネガティブなことが出てきても消さなくていいんです。
そのまま書いておいてください。

【要一次情報：オーナーが「ちょっと嫌」から自分の大切にしたいことに気づいた体験がほしい（どんな「嫌」が、どんな価値観につながったか）】

**1夜目のゴール**：心地いいこと・ちょっと嫌なことのリストができていれば十分です。数は気にしなくて大丈夫です。

## STEP2（2夜目）：「私らしさ」を3つの言葉にする

2夜目は、1夜目のリストを眺めて、共通する「大切にしたいこと」を3つの言葉にします。

### 集めた出来事に共通する「大切にしたいこと」を見つける問い

リストを見ながら、次の問いを順番に考えてみてください。

11. リストの中で、読み返して心が動いたものに印をつけるとしたら、どれですか。
12. 印をつけた出来事に、共通している「気持ち」は何ですか（ほっとした、わくわくした、など）。
13. その気持ちになれたのは、そこに何があったからですか（自由、仲間、静けさ、など）。
14. 「ちょっと嫌」の裏側には、どんな「本当はこうしたい」が隠れていますか。

### キーワードを3つに絞るコツ

まずは思いつくだけ出して、あとから3つに絞ります。

1. 問い13・14で出てきた言葉を、すべて書き出す
2. 特典の「価値観キーワード一覧」を眺めて、ピンとくる言葉を足す
3. 似ている言葉をまとめる（「自由」と「自分のペース」など）
4. 最後に「これがない毎日は、私らしくない」と思うものを3つ選ぶ

3つに決めきれなければ、4つや5つのままでもかまいません。
今日の3つは、来月変わってもいいんです。

### 「きれいな言葉」じゃなくていい ── 自分の言葉に言い換える

一覧にある言葉は、あくまで手がかりです。

「誠実さ」より「うそをつかなくていい場所」のほうがしっくりくるなら、そちらを使ってください。
少し長くても、ちょっと不格好でもいいんです。
自分が読んで「そうそう」と思える言葉がいちばんです。

【要一次情報：オーナー自身の「私らしさ」の3つのキーワードと、それを選んだ理由（公開してよい範囲で）】

**2夜目のゴール**：「私らしさ」を表す言葉が、だいたい3つ書けていれば十分です。

## STEP3（3夜目）：理想の未来の「なんでもない1日」を描く

3夜目は、大きな夢ではなく、理想の未来の「ふつうの1日」を描きます。

### 大きな夢ではなく、朝起きてから眠るまでを描く理由

「将来の夢」を聞かれると、多くの人が肩書きや成果を考えます。
でも、毎日を形づくっているのは、もっと小さな場面です。

どんな部屋で目覚めて、誰と話して、どんな気分で眠るのか。
そこに、2夜目の3つの言葉がどう表れているかを見ていきます。

いつの未来にするかは自由です。
「3年後」くらいが、遠すぎず近すぎず描きやすいと思います。

【要一次情報：オーナーが「大きな夢より日常を描く」ことの大切さに気づいた体験、またはワークショップでこのステップをしたときの参加者の様子（掲載許可のある範囲で）】

### 五感で書くテンプレート

次の表を埋めるように書いてみてください。すべて埋めなくて大丈夫です。

| 時間 | どこで | 誰と | 何を着て | 何をしている | どんな気分 | 聞こえる音・香り |
|---|---|---|---|---|---|---|
| 朝 | | | | | | |
| 昼 | | | | | | |
| 夜 | | | | | | |

書き終えたら、次の問いに答えてみてください。

15. この1日の中で、いちばん「いいな」と感じる場面はどこですか。
16. その場面に、2夜目の3つの言葉はどう表れていますか。
17. この1日を過ごしたあと、眠る前のあなたはどんな言葉をつぶやいていそうですか。

### 「〜しなきゃ」が出てきたら、そっと横に置く方法

書いていると、「でも現実的じゃない」「こんなの無理」という声が出てくることがあります。

そのときは、ノートの端に「〜しなきゃ」メモ欄をつくって、そこに書き出してください。
消さなくていいんです。
いったん横に置いて、また理想の1日に戻ってきましょう。

今日は「できるかどうか」ではなく「どうだったらうれしいか」を書く日です。

**3夜目のゴール**：理想の未来の1日が、1ページ分くらい言葉になっていれば十分です。

## STEP4（4夜目）：今日からの"小さな一歩"を1つだけ決める

最後の夜は、理想の1日に近づくための「小さな一歩」を1つだけ決めます。

### 理想の1日と、今の1日の「重なる部分」を探す

まず、今の自分のふつうの1日を、3夜目と同じ表でざっくり書いてみます。
そして、2つの1日を並べて見比べてみてください。

18. 理想の1日と今の1日で、すでに重なっている部分はどこですか。
19. 理想の1日の中で、今の暮らしにほんの少しだけ持ってこられそうな場面はどこですか。

「すでに重なっている部分」が見つかったら、それはあなたがもう大切にできていることです。
そこにも、ちゃんと目を向けてあげてください。

### 一歩の大きさの目安

一歩は、小さければ小さいほどいいと考えています。目安は3つです。

- 5分でできる
- お金がかからない（またはほとんどかからない）
- 誰にも言わなくていい

たとえば「朝、5分だけ窓を開けてお茶を飲む」くらいの大きさです。
「転職する」「資格をとる」は、一歩ではなく、ずっと先のゴールです。

20. 次の1週間で、5分あればできる「理想の1日のかけら」は何ですか。

これを、1つだけ決めてください。

【要一次情報：オーナー自身が決めた"小さな一歩"と、その後どうなったか（続いた・続かなかったも含めて。失敗談があるとなおよい）】

### 1か月後・3か月後の見直し方

1か月後と3か月後に、このノートを開く日をカレンダーに入れておきましょう。

見直すときは、次の3つだけ書いてみてください。

- 小さな一歩をやってみて、どんな気持ちになったか
- 3つの言葉は、今もしっくりくるか
- 理想の1日に、書き足したい・消したい場面はあるか

できなかったことを数える必要はありません。
「やってみてどうだったか」だけでいいんです。
特典のワークシートにも、見直し用の欄を用意しています。

**4夜目のゴール**：明日から試せる小さな一歩が、1つ決まっていれば十分です。

## 記入例：2人の女性のワーク

ここでは、書き方のイメージをつかむために、2人の記入例を紹介します。

### 例1：会社員・32歳「仕事は嫌いじゃないけど、このままでいいのか分からない」（架空）

**STEP1：心地いい／ちょっと嫌**
- 心地いい：休日にひとりで美術館に行く時間。後輩の相談にのって「助かりました」と言われたとき。
- ちょっと嫌：会議で、決まったことが翌日ひっくり返ること。飲み会で愛想笑いを続けること。

**STEP2：私らしさの3つの言葉**
- 「ひとりで味わう時間」
- 「誰かの役に立てている実感」
- 「うそのない会話」

**STEP3：理想の未来の1日（一部）**
- 朝：少し早く起きて、ベランダで植物に水をやる。
- 昼：小さなチームで、相手の顔が見える仕事をしている。
- 夜：寄り道して本屋さんに行き、気になった1冊を買って帰る。

**STEP4：小さな一歩**
- 「月に1回、仕事帰りにひとりで美術館か本屋に寄る日をつくる」

### 例2：子育て中・35歳「自分のことを考える時間がなかった」（架空）

**STEP1：心地いい／ちょっと嫌**
- 心地いい：子どもが寝たあと、温かいお茶を飲む10分。学生時代、文化祭のポスターを描いていたこと。
- ちょっと嫌：「ママなんだから」と言われること。予定を自分で決められないこと。

**STEP2：私らしさの3つの言葉**
- 「自分で選ぶ」
- 「手を動かしてつくる」
- 「ほっとする時間」

**STEP3：理想の未来の1日（一部）**
- 朝：家族と朝ごはんを食べたあと、30分だけ自分の時間がある。
- 昼：週に何日か、絵や手しごとに関わることをしている。
- 夜：今日は何をしたかを、誰かに話せる。

**STEP4：小さな一歩**
- 「子どもが寝たあとのお茶の時間に、5分だけ落書きをする」

2人とも、立派な言葉は書いていません。
こんなに素朴でいいんだ、と思ってもらえたらうれしいです。

## うまく書けないときのQ&A

つまずいたときは、ここに戻ってきてください。

**Q1. 何も思い浮かびません。**
A. 「何も思い浮かばない」と、そのまま書いてみてください。
そのうえで、問いの範囲を「今日1日」まで小さくしてみましょう。「今日、少しでもほっとしたこと」なら見つかるかもしれません。

**Q2. ネガティブなことばかり出てきます。**
A. それで大丈夫です。STEP1でお伝えしたように、「嫌」は大切にしたいものの裏返しであることが多いです。
ただ、書いていてつらくなったら、その日はノートを閉じて休んでください。

**Q3. 理想の1日が、現実離れしている気がします。**
A. 現実離れしていても、かまいません。
その1日の中から「今の暮らしに持ってこられるかけら」を探すのがSTEP4です。かけらは、とても小さくていいんです。

**Q4. 途中で止まってしまいました。**
A. 止まった場所から、また始めれば大丈夫です。
1か月あいても、半年あいても、ノートは待っていてくれます。

**Q5. 3つの言葉が、毎回変わります。**
A. 変わっていいんです。
今のあなたにしっくりくる言葉が、今の答えです。変わっていく過程も、あなたらしさの一部です。

**Q6. 書いたものを、誰かに見せたほうがいいですか。**
A. 見せなくて大丈夫です。
もし見せたくなったら、否定せずに聞いてくれる人を選んでください。
