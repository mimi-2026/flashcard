# note制作チーム

`/note-team <ジャンル>` で起動。オーナーは最後に `00_判断シート.md` を見て選ぶだけ。

- `.claude/agents/note-*.md` … 6人の担当（ネタ・構成・執筆・特典・導線・数字）
- `.claude/skills/note-team/` … 進行役
- `note/primary/` … あなたの一次情報（ここに体験メモを入れるほど本文が強くなる）
- `note/articles/<slug>/` … 記事ごとの成果物
- `note/metrics.md` … 売上・反応の記録（公開後に数字を伝えると数字担当が追記）
